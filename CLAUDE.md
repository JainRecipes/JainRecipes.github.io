# Project Guidelines

## General

- Explain your plan before editing multiple files.
- Do not commit or push changes.
- Ask before deleting files.
- Prefer small, reviewable changes.

## Jekyll

- Preserve existing front matter.
- Keep generated files out of commits.
- Follow the existing directory structure.

## JavaScript

- Prefer modern ES6+ syntax.
- Avoid adding new dependencies unless necessary.

## Testing

- If a local build command exists, run it before finishing.
- Report any build errors rather than silently ignoring them.

## Safety

- Never run `git commit`, `git push`, `git tag`, or `git rebase` unless I explicitly ask.
- Before editing more than three files, present a brief implementation plan and wait for approval.
- Prefer incremental changes over large refactors.
